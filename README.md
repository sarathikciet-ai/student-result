\# Student Result Processing System



\## Description



The Student Result Processing System is a modular Command Line Interface application developed using the Go programming language.



The application accepts student details and subject marks, then calculates the total marks, average marks, grade, and pass or fail result.



\## Features



\- Accepts student name

\- Accepts roll number

\- Accepts marks for multiple subjects

\- Calculates total marks

\- Calculates average marks

\- Assigns grade

\- Determines pass or fail status

\- Uses modular Go packages

\- Uses Git for version control

\- Uses GitHub for project collaboration



\## Technologies Used



\- Go 1.27.1

\- Go Modules

\- Git

\- GitHub

\- Visual Studio Code
